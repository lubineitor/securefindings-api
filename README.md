# SecureFindings API

> Proyecto en desarrollo orientado a la gestión de hallazgos de seguridad mediante una API REST desarrollada en Java.

## Estado

🚧 **En desarrollo**

El proyecto se encuentra actualmente en una fase inicial de implementación.

Su objetivo es servir como proyecto práctico para profundizar en la intersección entre:

- Java
- Desarrollo backend
- Application Security
- OWASP
- Secure Coding
- Testing

## Objetivo

SecureFindings pretende proporcionar una API para registrar y gestionar hallazgos de seguridad, aplicando progresivamente principios de desarrollo seguro.

Entre los conceptos que se están trabajando se encuentran:

- Gestión de hallazgos
- Severidad y estado
- Validación de datos
- Manejo controlado de errores
- Persistencia
- Testing
- Control de acceso
- Seguridad de la API

## Tecnologías

Actualmente:

- Java
- Maven
- Spring
- JUnit
- Docker

> El stack puede evolucionar a medida que avance el desarrollo.
